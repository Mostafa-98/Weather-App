# Weather App

A weather forecast app that shows current conditions and a 3-day forecast for any city, with search-as-you-type.

**Live demo:** https://mostafa-98.github.io/Weather-App/

## Features

- Search any location (searches as you type)
- Current temperature, condition, wind and humidity
- Today / tomorrow / day-after forecast cards
- Inline error message for unknown locations

## Built with

- HTML5, CSS3, Bootstrap 5
- Vanilla JavaScript (fetch API)
- [WeatherAPI.com](https://www.weatherapi.com/) forecast API
